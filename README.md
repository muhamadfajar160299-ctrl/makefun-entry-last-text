The funniest final text a dying phone sends at one percent battery —
one message, in the phone's own voice, under 200 characters.

`main.py` (Python standard library only) copies `entry.txt` straight to
`$MAKEFUN_OUTPUT_DIR/entry.txt` with a single direct write, mode 0644.
